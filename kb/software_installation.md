# Software Installation Policy

Document ID: KB-007
Owner: IT Service Desk and Security Team
Last reviewed: 2026-11-01

## Approved software
Install approved software from the Software Center. It lists the tools that have been reviewed and can be installed without a ticket.

## Requesting new software
If a tool is not in the Software Center, submit a request with the software name, the vendor, the version and the business purpose. The Security Team reviews each request, usually within 5 working days.

## Not allowed
Pirated, cracked or unlicensed software is never allowed. Browser extensions must come from the approved list. Software downloaded from unknown websites will be removed.

## Administrator rights
Employees do not have administrator rights by default. Temporary administrator rights can be granted for a maximum of 24 hours with line manager approval and a clear reason.

## Open-source tools
Open-source tools follow the same request and review process as commercial software.

## Compliance checks
IT scans company devices regularly. Unapproved software found during a scan is removed and may be reported to your manager.

## If an install fails
Restart the device and try again. If it still fails, create a ticket with the software name and the exact error message.
