# Multi-Factor Authentication Policy

Document ID: KB-005
Owner: IT Security and Identity Team
Last reviewed: 2026-11-01

## Who must use MFA
All employees must use multi-factor authentication on every company account. Accounts without MFA are restricted.

## Setting up MFA
Install an authenticator app on your phone. Sign in to the self-service portal, open Security settings, choose "Add authenticator", scan the QR code and enter the six-digit code shown in the app.

## Backup codes
Save your backup codes in a safe place, such as a password manager. Each code works once. Do not store them in an email or an unprotected file.

## Changing your phone
Move your authenticator before you give up your old phone if possible. If you have already lost access, contact the Service Desk. An MFA reset requires identity verification and confirmation from your line manager.

## Unexpected prompts
If you receive an MFA prompt you did not trigger, deny it and report it to the Security Team immediately. It may mean someone has your password.

## Sharing codes
Never share an MFA code with anyone, including IT staff. Anyone who asks for a code is not legitimate.

## What IT will never do
The Service Desk never asks you to read out or send an authentication code.
