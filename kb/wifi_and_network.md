# Wi-Fi and Network Policy

Document ID: KB-008
Owner: IT Network Team
Last reviewed: 2026-11-01

## Office networks
Nimbus-Corp is for company devices and requires your company login. Nimbus-Guest is for visitors and personal devices. It provides internet access only, with no access to internal systems. The Guest access code changes daily.

## Personal devices
Personal phones and laptops must connect to Nimbus-Guest only, never to Nimbus-Corp.

## If you cannot connect to Wi-Fi
1. Turn Wi-Fi off and on again.
2. Forget the network and reconnect.
3. Restart your device.
4. Check whether other people nearby have the same problem.
5. If it still fails, create a ticket with your location, device type and the time.

## Slow connection
Report slow speeds with the location, the time and a speed test result if possible. This helps the Network Team find the cause.

## Network outages
If many people on a floor lose connection at once, report it as an outage ticket so it is prioritised.

## Not allowed
Do not connect personal routers, hotspots or switches to the office network. Never share the Nimbus-Corp login or the Guest code outside the intended group.

## Using public Wi-Fi
When working away from the office on public Wi-Fi, connect to the company VPN before opening any company system.
